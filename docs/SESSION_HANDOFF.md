# یادداشت تحویل سشن

سند زنده‌ی «از کجا ادامه بدهیم». وضعیت‌های زیر در تاریخ نگارش از خودِ
git و GitHub خوانده شده‌اند — **در شروع هر سشن دوباره بررسی‌شان کنید**،
به این سند به‌عنوان حقیقت جاری اتکا نکنید.

آخرین به‌روزرسانی: ۲۰۲۶-۰۹-۱۱

## ۱. هدف محصول

ابزار **شخصی و محلی** تحلیل اختیار معامله‌ی بازار ایران:

- انتخاب فرصت‌های واقعاً قابل معامله (نقدشوندگی، هزینه‌ی اجرا، سرمایه‌ی
  لازم، ریسک)
- معاملات کاغذی و بک‌تست **معتبر**
- پیش‌بینی احتمالاتی وضعیت بازار و نماد پایه **تا سررسید**
- اتصال اخبار از یک سرویس لوکالِ مستقل (مخزن جدا)
- در ادامه: دستیار داخل رابط کاربری

**اجرای واقعی سفارش در دامنه نیست.**
**سودآوری هنوز اثبات نشده است** — هیچ عددی از بک‌تست یا گزارش فعلی
شاهد مزیت معاملاتی نیست (بخش ۷).

## ۲. روش همکاری

محمد هدف و اولویت را تعیین می‌کند؛ **اختیار طراحی و اجرای فنی با
دستیار است**. انتخاب‌های معمول فنی تأیید مجدد نمی‌خواهند.

کار تا **نتیجه‌ی قابل استفاده، بررسی و PR** جلو می‌رود. مرحله‌ی طراحیِ
جدا فقط برای ابهام یا مانع واقعی.

تست محدود به **خطرهای واقعی** (اشتباه محاسبه‌ی مالی، خرابی داده،
قرارداد اجزا). تعداد تست و درصد پوشش هدف نیست.

بازبینی با کدکس انجام می‌شود و **merge فقط با تصمیم صریح محمد**.

## ۴. آنچه آماده است

**recorder** زنجیره‌ی خام بازار را **پیش از** فیلترهای کیفیت ثبت
می‌کند (SQLite، payload خام به‌صورت BLOB فشرده). به‌همراه اصلاحات
صحت داده، اسکیمای **نسخه ۳**، و قابلیت `--loop` (در PR #4).

دستورها — **working directory باید `option_signal_bot/` باشد**:

```powershell
cd D:\Users\M.Kharmandar\Desktop\Codes\optionbaz\Kh-Optionbaz\option_signal_bot

.\.venv\Scripts\python.exe scripts\record_market.py --once     # یک نوبت
.\.venv\Scripts\python.exe scripts\record_market.py --loop     # ثبت منظم
.\.venv\Scripts\python.exe scripts\record_market.py --status   # بدون شبکه

# آزمایشی، کاملاً آفلاین (پایگاه جدا)
.\.venv\Scripts\python.exe scripts\record_market.py --loop --kind test `
    --fixture tests\fixtures\tsetmc_option_market_watch.json --interval 30
```

توقف: **Ctrl+C** — قفل آزاد، اتصال بسته، خلاصه، خروج ۰.
کد خروجی: `0` موفق · `1` دریافت/پردازش ناموفق · `2` استفاده‌ی نادرست.

**تنظیمات مؤثر** (بخش `recorder` در `config/settings.yaml`):
`interval_seconds: 300` · `timezone: Asia/Tehran` ·
`session_start/end: 09:00–12:30` · `closing_grace_seconds: 300` ·
`sqlite_path` و `test_sqlite_path`. آرگومان صریح CLI مقدم است.

**محدودیت‌های مهم:**

- **تاریخچه‌ی ازدست‌رفته بازسازی نمی‌شود.** ماشین که خاموش بماند، آن
  بازه رفته است.
- **جبران انبوه وجود ندارد** (عمدی): پس از خواب سیستم، اسلات‌های
  جامانده پرش می‌شوند.
- **snapshotهای پس از پایان جلسه «قیمت پایانی» نیستند** — منبع هیچ مهر
  زمانی نمی‌دهد، پس `source_time` همیشه `NULL` است.
- **عمق فقط سطح‌اول** است (از خود payload). عمق پنج‌سطحی نیاز به یک
  درخواست به‌ازای هر قرارداد دارد و اضافه نشده.
- **rate limit اندازه‌گیری نشده** — هفته‌ی اول باید پایش شود.
- **Ctrl+C فقط با تست شبیه‌سازی‌شده تأیید شده**، نه در کنسول واقعی.
- **Task Scheduler نصب نشده** (عمدی). فعلاً یک پنجره‌ی PowerShell باز
  بماند و سیستم خواب نرود؛ پس از restart دستی دوباره اجرا شود.

## ۵. داده و پردازه‌های محلی

همه زیر `option_signal_bot/var/recorder/` — **در `.gitignore`، هیچ
داده‌ای وارد Git نمی‌شود** (تأییدشده).

**پردازه‌ی فعال: هیچ.** در زمان نگارش هیچ پردازه‌ی پایتونی در اجرا
نبود و هیچ قفلی در اختیار کسی نبود.

**پایگاه فعال: هیچ.** هر دو مسیر پیش‌فرض (`market.db` و `test.db`)
خالی‌اند؛ اولین اجرا پایگاه تازه‌ی **v3** می‌سازد.

**پایگاه‌های قدیمی — نگه داشته شوند:**

| فایل | نسخه |
|---|---|
| `market-schema-v1.db`، `test-schema-v1.db` | ۱ |
| `market-schema-v2-inscode.db` | ۲ (ستون `ins_code`) |
| `test-schema-v2-key.db` | ۲ (ستون‌های `kind`/`key`) |
| `backup-2026*/` (سه پوشه) | پشتیبان‌های سازگارِ SQLite |

⚠️ **هیچ‌کدام بدون اجازه‌ی محمد حذف یا بازنویسی نشوند.** کد فعلی آن‌ها
را با `SchemaVersionMismatch` رد می‌کند و **دست نمی‌زند** — مهاجرت
خودکار عمداً وجود ندارد. برای خواندنشان یا همان نسخه‌ی کد لازم است یا
`sqlite3` مستقیم.

### بررسی وضعیت و توقف در سشن جدید

```powershell
# آیا recorder فعال است؟
tasklist /FI "IMAGENAME eq python.exe"
Get-ChildItem var\recorder\*.lock          # قفل = نمونه‌ی فعال

# وضعیت داده (بدون شبکه)
.\.venv\Scripts\python.exe scripts\record_market.py --status

# توقف: Ctrl+C در همان پنجره. اگر پنجره در دست نیست:
taskkill /PID <PID> /F                     # قفل خودکار آزاد می‌شود
```

نمونه‌ی دوم روی یک پایگاه با قفل سیستم‌عامل رد می‌شود، ولی **پیش از
اجرا بررسی کنید** تا با پیام خطا روبه‌رو نشوید.

⚠️ **نرخ کارمزد، مالیات، فرمول وجه تضمین و قواعد رسمی تسویه‌ی بورس
